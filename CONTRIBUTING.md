# Contributing

Create changes on a short-lived branch and open a pull request against `main`.
Pull requests must explain the affected delivery requirement, test evidence
and any remaining limitation.

Use focused titles such as:

- `feat: accept GeoJSON polygon analysis areas`
- `fix: distinguish PDOK failure from empty coverage`
- `test: verify point summary against reference data`

All automated checks must pass. Changes to the public process schema,
classification method, callback security or deployment architecture require
review from the relevant workstream owner.
